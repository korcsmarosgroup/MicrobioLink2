## Agent skills

> Internal agent/dev docs live under `ai_docs/` (plans, decisions, agent config). `docs/` is reserved for the published Zensical documentation site — don't put internal docs there.

### Issue tracker

Issues and PRDs live as GitHub issues on `korcsmarosgroup/MicrobioLink2` (via the `gh` CLI). See `ai_docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `ai_docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` at the repo root, decision records in `ai_docs/decisions/`. See `ai_docs/agents/domain.md`.
