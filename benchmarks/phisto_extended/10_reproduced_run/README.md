# Package-Generated Outputs

This directory is reserved for outputs produced by the interactive benchmark
walkthrough notebook.

The canonical documented benchmark remains in:

- `../05_results/`
- `../08_figures/`

When you rerun the benchmark through the notebook, the regenerated files are
written here instead of overwriting the original reference bundle. The notebook
creates subdirectories such as:

- `01_accessions/`
- `02_raw_uniprot_downloads/`
- `04_benchmark_inputs/`
- `05_results/`
- `07_metadata/`
